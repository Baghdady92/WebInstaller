1 · Enable ADB on the car (once)

Enter this code in the car's ADB menu ——————

First, dial this in the car's Phone app
  1. Bluetooth OFF — turn Bluetooth off in the car, then open the built-in Phone app.
  2. Dial the code above — the hidden engineering menu opens.
  3. Plug in the cable — data cable into the upper driver-side USB-A port (USB-A↔USB-A from a computer, or an OTG adapter from a phone).
  4. Enter the 6-digit code — it's tied to the car's clock; adjust the Region / Car-clock rows above until the time shown matches the car's screen.
  5. Turn ADB ON — if the USB light blinks off, unplug and replug the cable.
  6. Continue below — press Connect in step 2 and approve the prompt on the car screen.
Troubleshooting
  • Wrong code? The code follows the CAR's clock. Compare the time shown above with the car's screen and use the Car-clock row to correct it.
  • Menu doesn't open? Bluetooth must be OFF before dialing. Dial exactly, including the *#…#* wrappers.
  • No USB device found? Use a data cable (not charge-only) and the upper driver-side USB-A port. Try another cable.
  • Connection drops? Replug the cable after turning ADB on; cheap OTG adapters are a common culprit.
